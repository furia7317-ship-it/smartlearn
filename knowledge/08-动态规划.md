# 第8章 动态规划

## 8.1 动态规划的基本思想

动态规划（Dynamic Programming, DP）是将复杂问题分解为重叠子问题，通过保存子问题的解避免重复计算。

**适用条件**：
1. **最优子结构**：问题的最优解包含子问题的最优解
2. **重叠子问题**：子问题被多次计算
3. **无后效性**：当前状态只与之前状态有关，与之后的决策无关

## 8.2 斐波那契数列

最简单的 DP 示例。

```python
# 递归（有大量重复计算）
def fib_recursive(n):
    if n <= 1:
        return n
    return fib_recursive(n - 1) + fib_recursive(n - 2)

# 动态规划（自底向上）
def fib_dp(n):
    if n <= 1:
        return n
    dp = [0] * (n + 1)
    dp[0], dp[1] = 0, 1
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]

# 空间优化
def fib_optimized(n):
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b
```

## 8.3 背包问题

### 0-1 背包

n 个物品，每个物品有重量 w[i] 和价值 v[i]，背包容量为 W。每个物品只能选一次。

```python
def knapsack_01(weights, values, W):
    n = len(weights)
    # dp[i][w] = 前 i 个物品、容量 w 时的最大价值
    dp = [[0] * (W + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for w in range(W + 1):
            dp[i][w] = dp[i-1][w]  # 不选第 i 个
            if w >= weights[i-1]:
                dp[i][w] = max(dp[i][w], dp[i-1][w - weights[i-1]] + values[i-1])

    return dp[n][W]

# 空间优化（一维）
def knapsack_01_optimized(weights, values, W):
    dp = [0] * (W + 1)
    for i in range(len(weights)):
        for w in range(W, weights[i] - 1, -1):  # 逆序遍历！
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
    return dp[W]
```

- 时间复杂度：O(nW)
- 空间复杂度：O(W)（优化后）

### 完全背包

每个物品可以选无限次。

```python
def knapsack_complete(weights, values, W):
    dp = [0] * (W + 1)
    for i in range(len(weights)):
        for w in range(weights[i], W + 1):  # 正序遍历！
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
    return dp[W]
```

## 8.4 最长公共子序列（LCS）

```python
def lcs(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i-1] == text2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    return dp[m][n]
```

- 时间复杂度：O(mn)
- 空间复杂度：O(mn)（可优化到 O(min(m,n))）

## 8.5 最长递增子序列（LIS）

```python
def lis(nums):
    if not nums:
        return 0
    dp = [1] * len(nums)  # dp[i] = 以 nums[i] 结尾的 LIS 长度

    for i in range(1, len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)

    return max(dp)
```

- 时间复杂度：O(n²)
- 优化：贪心 + 二分查找可达到 O(n log n)

## 8.6 编辑距离

将 word1 转换为 word2 所需的最少操作数（插入/删除/替换）。

```python
def edit_distance(word1, word2):
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i-1] == word2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(
                    dp[i-1][j],     # 删除
                    dp[i][j-1],     # 插入
                    dp[i-1][j-1]    # 替换
                )

    return dp[m][n]
```

## 8.7 DP 解题步骤

1. **定义状态**：明确 dp[i] 或 dp[i][j] 代表什么
2. **状态转移方程**：dp[i] 与之前状态的关系
3. **初始化**：边界条件
4. **遍历顺序**：确保计算 dp[i] 时依赖的状态已计算
5. **返回值**：dp 数组中哪个是答案
