# 第3章 栈和队列

## 3.1 栈

### 定义
栈（Stack）是限定仅在表尾进行插入和删除操作的线性表。栈遵循**后进先出**（LIFO）原则。

### Python 实现
```python
class Stack:
    def __init__(self):
        self.items = []

    def push(self, elem):
        """入栈"""
        self.items.append(elem)

    def pop(self):
        """出栈"""
        if self.is_empty():
            raise IndexError("栈为空")
        return self.items.pop()

    def peek(self):
        """查看栈顶元素"""
        if self.is_empty():
            raise IndexError("栈为空")
        return self.items[-1]

    def is_empty(self):
        return len(self.items) == 0

    def size(self):
        return len(self.items)
```

### 应用场景
1. **括号匹配**：检查表达式中的括号是否匹配。
2. **表达式求值**：将中缀表达式转换为后缀表达式并求值。
3. **函数调用栈**：程序运行时的函数调用管理。
4. **浏览器后退**：记录浏览历史。

### 括号匹配示例
```python
def is_balanced(expr):
    stack = Stack()
    pairs = {')': '(', ']': '[', '}': '{'}
    for char in expr:
        if char in '([{':
            stack.push(char)
        elif char in ')]}':
            if stack.is_empty() or stack.pop() != pairs[char]:
                return False
    return stack.is_empty()
```

## 3.2 队列

### 定义
队列（Queue）是限定仅在表尾插入、在表头删除的线性表。队列遵循**先进先出**（FIFO）原则。

### 循环队列
```python
class CircularQueue:
    def __init__(self, capacity):
        self.data = [None] * capacity
        self.front = 0
        self.rear = 0
        self.capacity = capacity

    def enqueue(self, elem):
        """入队"""
        if self.is_full():
            raise Exception("队列已满")
        self.data[self.rear] = elem
        self.rear = (self.rear + 1) % self.capacity

    def dequeue(self):
        """出队"""
        if self.is_empty():
            raise Exception("队列为空")
        elem = self.data[self.front]
        self.front = (self.front + 1) % self.capacity
        return elem

    def is_empty(self):
        return self.front == self.rear

    def is_full(self):
        return (self.rear + 1) % self.capacity == self.front
```

### 应用场景
1. **BFS 广度优先搜索**：图的层次遍历。
2. **打印队列**：任务调度。
3. **缓冲区**：生产者-消费者模型。

## 3.3 栈和队列的对比

| 特性 | 栈 | 队列 |
|------|-----|------|
| 原则 | LIFO（后进先出） | FIFO（先进先出） |
| 插入 | 栈顶 push | 队尾 enqueue |
| 删除 | 栈顶 pop | 队头 dequeue |
| 典型应用 | 括号匹配、递归 | BFS、任务调度 |
