# 第10章 回溯与分支限界

## 10.1 回溯法

回溯法是一种系统地搜索问题所有解的算法，采用深度优先策略。

**基本思想**：从根节点出发，按深度优先遍历解空间树。当发现当前节点不满足约束条件或不可能产生最优解时，回溯到上一个节点，尝试其他分支。

### 解空间树
- **子集树**：每个节点有选/不选两种选择，共 2ⁿ 个叶子
- **排列树**：n 个元素的全排列，共 n! 个叶子

## 10.2 N 皇后问题

在 N×N 棋盘上放置 N 个皇后，使其互不攻击。

```python
def n_queens(n):
    results = []

    def backtrack(row, cols, diag1, diag2, board):
        if row == n:
            results.append(["".join(r) for r in board])
            return

        for col in range(n):
            if col in cols or (row - col) in diag1 or (row + col) in diag2:
                continue

            board[row][col] = 'Q'
            backtrack(
                row + 1,
                cols | {col},
                diag1 | {row - col},
                diag2 | {row + col},
                board
            )
            board[row][col] = '.'

    backtrack(0, set(), set(), set(), [['.'] * n for _ in range(n)])
    return results
```

- 时间复杂度：O(N!)（实际剪枝后远小于此）

## 10.3 子集和问题

给定正整数集合和目标值，找出所有和为目标值的子集。

```python
def subset_sum(nums, target):
    results = []

    def backtrack(start, path, remaining):
        if remaining == 0:
            results.append(path[:])
            return
        if remaining < 0:
            return

        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1, path, remaining - nums[i])
            path.pop()

    backtrack(0, [], target)
    return results
```

## 10.4 全排列

```python
def permutations(nums):
    results = []

    def backtrack(path, used):
        if len(path) == len(nums):
            results.append(path[:])
            return

        for i in range(len(nums)):
            if used[i]:
                continue
            used[i] = True
            path.append(nums[i])
            backtrack(path, used)
            path.pop()
            used[i] = False

    backtrack([], [False] * len(nums))
    return results
```

## 10.5 组合总和

```python
def combination_sum(candidates, target):
    results = []

    def backtrack(start, path, remaining):
        if remaining == 0:
            results.append(path[:])
            return

        for i in range(start, len(candidates)):
            if candidates[i] > remaining:
                break  # 剪枝（需排序）
            path.append(candidates[i])
            backtrack(i, path, remaining - candidates[i])  # i 不是 i+1，允许重复
            path.pop()

    candidates.sort()
    backtrack(0, [], target)
    return results
```

## 10.6 分支限界法

分支限界法与回溯法类似，但使用广度优先或优先队列搜索，并通过限界函数剪枝。

**关键区别**：
- 回溯法：DFS，找所有解或一个解
- 分支限界法：BFS/优先队列，找最优解

### 0-1 背包的分支限界解法

```python
import heapq

class Node:
    def __init__(self, level, value, weight, bound):
        self.level = level
        self.value = value
        self.weight = weight
        self.bound = bound

    def __lt__(self, other):
        return self.bound > other.bound  # 大根堆

def bound(node, n, W, weights, values):
    """计算上界：当前价值 + 剩余物品的贪心估计"""
    if node.weight >= W:
        return 0

    total_weight = node.weight
    total_value = node.value
    j = node.level + 1

    while j < n and total_weight + weights[j] <= W:
        total_weight += weights[j]
        total_value += values[j]
        j += 1

    if j < n:
        total_value += (W - total_weight) * values[j] / weights[j]

    return total_value

def branch_and_bound(weights, values, W):
    n = len(weights)
    # 按性价比排序
    items = sorted(range(n), key=lambda i: values[i]/weights[i], reverse=True)
    weights = [weights[i] for i in items]
    values = [values[i] for i in items]

    root = Node(-1, 0, 0, 0)
    root.bound = bound(root, n, W, weights, values)

    pq = [root]
    best_value = 0

    while pq:
        node = heapq.heappop(pq)

        if node.bound <= best_value:
            continue

        level = node.level + 1
        if level >= n:
            continue

        # 选择当前物品
        new_weight = node.weight + weights[level]
        new_value = node.value + values[level]

        if new_weight <= W and new_value > best_value:
            best_value = new_value

        left = Node(level, new_value, new_weight, 0)
        left.bound = bound(left, n, W, weights, values)
        if left.bound > best_value:
            heapq.heappush(pq, left)

        # 不选当前物品
        right = Node(level, node.value, node.weight, 0)
        right.bound = bound(right, n, W, weights, values)
        if right.bound > best_value:
            heapq.heappush(pq, right)

    return best_value
```

## 10.7 回溯 vs 分支限界

| 特性 | 回溯法 | 分支限界法 |
|------|--------|------------|
| 搜索策略 | DFS | BFS/优先队列 |
| 目标 | 所有解/一个解 | 最优解 |
| 剪枝 | 约束函数 | 限界函数 |
| 存储 | 栈 | 队列/堆 |
| 空间 | O(树深) | O(宽度) |
