# 第9章 贪心算法

## 9.1 贪心的基本思想

贪心算法在每一步选择中都采取当前状态下最好（最优）的选择，希望导致全局最优解。

**适用条件**：
1. **贪心选择性质**：局部最优选择能导致全局最优
2. **最优子结构**：问题的最优解包含子问题的最优解

## 9.2 活动选择问题

n 个活动，每个活动有开始时间和结束时间。求最大兼容活动子集。

```python
def activity_selection(activities):
    """activities: [(start, end), ...]"""
    # 按结束时间排序
    activities.sort(key=lambda x: x[1])

    selected = [activities[0]]
    last_end = activities[0][1]

    for start, end in activities[1:]:
        if start >= last_end:
            selected.append((start, end))
            last_end = end

    return selected
```

**证明贪心正确性**：按结束时间最早排序，每次选择结束最早的活动，为后续活动留下最多时间。

## 9.3 分数背包

物品可以分割，取部分重量。

```python
def fractional_knapsack(weights, values, W):
    """返回最大价值"""
    # 按性价比排序
    items = sorted(zip(values, weights), key=lambda x: x[0]/x[1], reverse=True)

    total_value = 0
    for v, w in items:
        if W >= w:
            total_value += v
            W -= w
        else:
            total_value += v * (W / w)
            break

    return total_value
```

## 9.4 哈夫曼编码

贪心构建最优前缀编码树。

```python
import heapq

class HuffmanNode:
    def __init__(self, char, freq):
        self.char = char
        self.freq = freq
        self.left = None
        self.right = None

    def __lt__(self, other):
        return self.freq < other.freq

def build_huffman_tree(freq_map):
    heap = [HuffmanNode(ch, f) for ch, f in freq_map.items()]
    heapq.heapify(heap)

    while len(heap) > 1:
        left = heapq.heappop(heap)
        right = heapq.heappop(heap)
        merged = HuffmanNode(None, left.freq + right.freq)
        merged.left = left
        merged.right = right
        heapq.heappush(heap, merged)

    return heap[0]

def get_codes(root, prefix="", code_map=None):
    if code_map is None:
        code_map = {}
    if root is None:
        return code_map
    if root.char is not None:
        code_map[root.char] = prefix
    get_codes(root.left, prefix + "0", code_map)
    get_codes(root.right, prefix + "1", code_map)
    return code_map
```

**性质**：
- 频率高的字符编码短，频率低的编码长
- 没有任何编码是另一个编码的前缀（前缀码）

## 9.5 Dijkstra 最短路径

贪心选择当前距离最近的未访问节点。

```python
import heapq

def dijkstra(graph, start):
    """graph: {node: [(neighbor, weight), ...]}"""
    dist = {start: 0}
    pq = [(0, start)]
    prev = {start: None}

    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float('inf')):
            continue
        for v, w in graph.get(u, []):
            new_dist = d + w
            if new_dist < dist.get(v, float('inf')):
                dist[v] = new_dist
                prev[v] = u
                heapq.heappush(pq, (new_dist, v))

    return dist, prev
```

**贪心正确性**：每次选择距离源点最近的未确定节点，由于边权非负，不可能通过其他路径得到更短距离。

## 9.6 最小生成树

### Kruskal 算法
按边权排序，依次加入不构成环的边。

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True

def kruskal(n, edges):
    """edges: [(weight, u, v), ...]"""
    edges.sort()
    uf = UnionFind(n)
    mst = []
    total = 0

    for w, u, v in edges:
        if uf.union(u, v):
            mst.append((u, v, w))
            total += w
            if len(mst) == n - 1:
                break

    return mst, total
```

### Prim 算法
从一个顶点开始，每次加入连接已选和未选的最小权边。

```python
import heapq

def prim(graph, start=0):
    """graph: {node: [(neighbor, weight), ...]}"""
    visited = set()
    mst = []
    total = 0
    pq = [(0, start, -1)]  # (weight, node, from)

    while pq and len(visited) < len(graph):
        w, u, fr = heapq.heappop(pq)
        if u in visited:
            continue
        visited.add(u)
        if fr != -1:
            mst.append((fr, u, w))
            total += w
        for v, weight in graph.get(u, []):
            if v not in visited:
                heapq.heappush(pq, (weight, v, u))

    return mst, total
```

## 9.7 贪心 vs 动态规划

| 特性 | 贪心 | 动态规划 |
|------|------|----------|
| 决策 | 局部最优 | 全局考虑 |
| 回溯 | 不回溯 | 需要枚举 |
| 效率 | 通常更快 | 可能较慢 |
| 正确性 | 需要证明 | 保证最优 |
| 典型问题 | 活动选择、分数背包 | 0-1背包、LCS |
