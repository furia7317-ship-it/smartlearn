# 第2章 线性表

## 2.1 线性表的定义

线性表是具有相同数据类型的 n（n≥0）个数据元素的有限序列。线性表是一种基本的线性结构。

## 2.2 顺序表

### 定义
用一组地址连续的存储单元依次存储线性表中的数据元素，使得逻辑上相邻的两个元素在物理位置上也相邻。

### Python 实现
```python
class SeqList:
    def __init__(self, capacity=10):
        self.data = [None] * capacity
        self.length = 0
        self.capacity = capacity

    def insert(self, i, elem):
        """在位置 i 插入元素"""
        if i < 0 or i > self.length:
            raise IndexError("插入位置不合法")
        if self.length >= self.capacity:
            self._resize()
        for j in range(self.length, i, -1):
            self.data[j] = self.data[j - 1]
        self.data[i] = elem
        self.length += 1

    def delete(self, i):
        """删除位置 i 的元素"""
        if i < 0 or i >= self.length:
            raise IndexError("删除位置不合法")
        elem = self.data[i]
        for j in range(i, self.length - 1):
            self.data[j] = self.data[j + 1]
        self.length -= 1
        return elem

    def _resize(self):
        """扩容"""
        self.capacity *= 2
        new_data = [None] * self.capacity
        for i in range(self.length):
            new_data[i] = self.data[i]
        self.data = new_data
```

### 时间复杂度
- 按位查找：O(1)
- 按值查找：O(n)
- 插入：O(n)（需要移动元素）
- 删除：O(n)（需要移动元素）

## 2.3 链表

### 单链表
```python
class Node:
    def __init__(self, data, next=None):
        self.data = data
        self.next = next

class LinkedList:
    def __init__(self):
        self.head = None
        self.size = 0

    def insert_head(self, elem):
        """头插法"""
        self.head = Node(elem, self.head)
        self.size += 1

    def insert_tail(self, elem):
        """尾插法"""
        if not self.head:
            self.head = Node(elem)
        else:
            cur = self.head
            while cur.next:
                cur = cur.next
            cur.next = Node(elem)
        self.size += 1

    def find(self, elem):
        """查找元素"""
        cur = self.head
        while cur:
            if cur.data == elem:
                return cur
            cur = cur.next
        return None

    def delete(self, elem):
        """删除元素"""
        if not self.head:
            return False
        if self.head.data == elem:
            self.head = self.head.next
            self.size -= 1
            return True
        cur = self.head
        while cur.next:
            if cur.next.data == elem:
                cur.next = cur.next.next
                self.size -= 1
                return True
            cur = cur.next
        return False
```

## 2.4 顺序表 vs 链表

| 特性 | 顺序表 | 链表 |
|------|--------|------|
| 存储方式 | 连续存储 | 离散存储 |
| 随机访问 | O(1) | O(n) |
| 插入/删除 | O(n) | O(1)* |
| 空间 | 需预分配 | 动态分配 |

*注：链表在已知位置的情况下插入/删除为 O(1)，但查找位置仍需 O(n)。
