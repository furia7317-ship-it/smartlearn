# 第7章 查找算法

## 7.1 查找的基本概念

查找是在数据集合中寻找满足特定条件的数据元素的过程。
- **查找表**：由同一类型的数据元素组成的集合。
- **关键字**：数据元素中某个数据项的值，用于标识数据元素。
- **平均查找长度（ASL）**：查找过程中关键字比较次数的期望值。

## 7.2 顺序查找

从表的一端开始，逐个比较关键字。

```python
def sequential_search(arr, target):
    for i, val in enumerate(arr):
        if val == target:
            return i
    return -1
```

- 时间复杂度：O(n)
- ASL成功 = (n+1)/2
- 适用：无序表，小规模数据

## 7.3 二分查找

**前提**：数据必须有序。

```python
def binary_search(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

- 时间复杂度：O(log n)
- ASL成功 ≈ log₂(n+1) - 1
- 适用：有序表，静态查找

### 二分查找判定树

二分查找的过程可以用一棵判定树来表示：
- 根节点是中间元素
- 左子树是左半部分的中间元素
- 右子树是右半部分的中间元素

判定树的高度 = ⌈log₂(n+1)⌉

## 7.4 二叉搜索树查找

```python
def bst_search(root, target):
    if not root or root.val == target:
        return root
    if target < root.val:
        return bst_search(root.left, target)
    return bst_search(root.right, target)
```

- 平均：O(log n)
- 最坏：O(n)（退化为链表）

## 7.5 平衡二叉树（AVL）

AVL 树是任何节点的左右子树高度差不超过 1 的 BST。

**旋转操作**：
1. LL 旋转（右旋）
2. RR 旋转（左旋）
3. LR 旋转（先左旋再右旋）
4. RL 旋转（先右旋再左旋）

```python
class AVLNode:
    def __init__(self, val):
        self.val = val
        self.left = None
        self.right = None
        self.height = 1

def get_height(node):
    return node.height if node else 0

def get_balance(node):
    return get_height(node.left) - get_height(node.right) if node else 0

def right_rotate(y):
    x = y.left
    T2 = x.right
    x.right = y
    y.left = T2
    y.height = 1 + max(get_height(y.left), get_height(y.right))
    x.height = 1 + max(get_height(x.left), get_height(x.right))
    return x

def left_rotate(x):
    y = x.right
    T2 = y.left
    y.left = x
    x.right = T2
    x.height = 1 + max(get_height(x.left), get_height(x.right))
    y.height = 1 + max(get_height(y.left), get_height(y.right))
    return y
```

- 查找时间复杂度：O(log n)（严格保证）

## 7.6 哈希查找

### 哈希函数
将关键字映射到表中位置的函数。

常用哈希函数：
- **除留余数法**：H(key) = key % p
- **直接定址法**：H(key) = a * key + b

### 冲突处理
1. **开放定址法**：线性探测、二次探测、双重哈希
2. **链地址法**：每个位置维护一个链表

```python
class HashTable:
    def __init__(self, size=10):
        self.size = size
        self.table = [[] for _ in range(size)]

    def _hash(self, key):
        return hash(key) % self.size

    def insert(self, key, value):
        idx = self._hash(key)
        for i, (k, v) in enumerate(self.table[idx]):
            if k == key:
                self.table[idx][i] = (key, value)
                return
        self.table[idx].append((key, value))

    def search(self, key):
        idx = self._hash(key)
        for k, v in self.table[idx]:
            if k == key:
                return v
        return None

    def delete(self, key):
        idx = self._hash(key)
        for i, (k, v) in enumerate(self.table[idx]):
            if k == key:
                del self.table[idx][i]
                return True
        return False
```

### 哈希查找效率
- 成功时平均比较次数取决于装填因子 α = n/m
- 开放定址法：ASL ≈ -1/α * ln(1-α)
- 链地址法：ASL ≈ 1 + α/2

## 7.7 查找算法对比

| 方法 | 平均时间 | 最坏时间 | 空间 | 适用场景 |
|------|----------|----------|------|----------|
| 顺序查找 | O(n) | O(n) | O(1) | 无序小表 |
| 二分查找 | O(log n) | O(log n) | O(1) | 有序静态表 |
| BST | O(log n) | O(n) | O(n) | 动态查找 |
| AVL | O(log n) | O(log n) | O(n) | 严格平衡 |
| 哈希 | O(1) | O(n) | O(n) | 快速查找 |
