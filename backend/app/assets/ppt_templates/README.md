# PPT 文件模板（母版）目录

把任意 `.pptx` 文件丢进这个目录，它就会作为一套**可选模板**出现在「生成 PPT 设置」里
（键名 `file:<文件名>`）。生成时会清掉该 .pptx 自带的样张幻灯片、保留它的母版 / 主题 /
配色 / 字体，再把课件内容灌进去。

建议放**只含母版与版式、内容尽量精简**的模板（标准版式：标题页 / 标题+内容 / 两栏内容
渲染效果最好）。版权提示：仅放你有权使用（自制或免费商用授权）的模板。

内置主题（无需文件、离线可用）：academic 学术简约 · tech 科技蓝 · warm 暖阳 ·
chalk 板书 · business 商务红 · fresh 清新绿。
