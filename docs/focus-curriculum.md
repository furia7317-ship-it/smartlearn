# 学习路径知识树

本次把章节下面的知识点、前置要求和个人学习记录拆开保存。页面仍使用 `DesktopShell` 与 `DesktopPath` 的主导航和页签；国策树是路径总览内部的组件。

## 数据和执行

- `focus_graphs`：课程内容和版本。包含章节、知识清单、稳定节点 ID、全部满足的前置 `all_of`、每组任选一项的 `any_of_groups`、建议关系与来源。已启用版本不提供直接编辑接口。
- `focus_progress`：个人当前节点、任务记录、通过记录、复习时间、每日时间预算和修订号。改变预算只重排今天的任务。
- `focus_packages`：绑定图和节点的讲解、示例、核验题与内容版本。获取接口不返回答案，提交后返回评分与解释。
- `focus_jobs`：课程草稿、节点资料的持久准备任务。刷新或离开页面不会取消；失败可重试。
- `focus_operations`：操作请求编号、摘要和结果。重复请求返回同一结果，旧修订号返回冲突。

`backend/app/schemas/focus.py` 检查引用、重复、知识覆盖、循环和可达性。`backend/app/services/focus.py` 判断解锁、排今日任务并评分。前端只呈现已保存的关系，不能用章节顺序或日期补造前置要求。

新课程先生成草稿。用户检查每章内容和依赖，可在节点详情调整必须先学的知识点，然后启用。章节归属不参与解锁；建议先学不阻止开始。主线、拓展和阶段成果分别标记。

阅读和示例练习只记录任务完成；核验答案由服务端评分，通过后才点亮。当前实现是概念题核验，不等同于真实项目或代码执行验收。复习答错不会抹去过去的通过记录。

## 页面

- `focus-workspace.tsx`：课程切换、搜索、草稿检查、详情和今日任务。
- `focus-tree-canvas.tsx`：React Flow 画布、键盘选择、缩放、平移、关联高亮和位置恢复。
- `focus-layout.ts`：ELK 按实际依赖排列章内分叉，再排章节；按图和版本缓存。跨章关系仍连接到同一张画布。
- `focus-study.tsx`：独立的讲解、练习和核验页面，可向现有智能教师提问。

手机宽度默认使用章节列表，保留切换完整树的入口。全部课程缩小时主要看结构；节点标题和说明可通过放大或详情阅读。书牌、纸面和山水使用 ImageGen 生成的图片，图中的线和箭头来自课程数据。

## 兼容范围

既有课程管理、资料阅读和旧学习计划继续使用原接口；旧课程可以把目录送入新图生成流程。旧资料的完成记录不自动换算成新节点通过记录。新的节点级记录目前不回写旧版首页掌握度统计，也没有把所有旧课程批量重新生成。

模型整理出的关系仍需要内容检查。结构校验能检查遗漏和循环，不能证明所有教学安排都合理；预览检查时曾将一条误设为硬前置的拓展内容改回建议学习。

## 验证与数据升级

后端测试见 `backend/tests/test_focus_curriculum.py`，覆盖图结构、前置条件、时间预算、任务与评分、账号归属、重复请求和草稿启用。前端布局测试见 `frontend/tests/focus-layout.test.mjs`。

数据库迁移 v9 会建立知识树所需的表。已有文件数据库在迁移前自动备份，备份位于数据库旁的 `.schema-backups/`。新增知识树不会替换旧账号和历史课程；旧资料的阅读记录也不会自动当作新节点核验通过。

作答和评分测试应在独立测试数据库中完成，避免把调试成绩写进实际学习记录。公开源码不附带任何用户数据库。
