# Windows 一键启动

双击项目根目录的 **启动学枢.cmd**。

- 检查 Node.js 24、Python 3.11 和已有依赖，启动 FastAPI 后端与 Next.js 开发前端。后端优先使用 `backend/.venv`，其次使用已有的 `frontend/runtime/python`。
- 默认地址为 **http://127.0.0.1:3000/desktop/**，后端为 **http://127.0.0.1:8000/**。两端就绪后自动打开浏览器；学习路径在 `/desktop/path/`，需要登录自己的账户。
- 已运行且确认属于本项目的健康服务会被复用。重复双击不会再启动一套服务；其他程序占用端口时会显示端口和 PID，不结束该程序。
- 使用时保持启动窗口开启。退出请先在窗口按 **回车**（或 Ctrl+C），仅停止这次创建的服务；复用的服务仍由原窗口管理。
- 出错时窗口会保留。日志在 `tmp/launcher/launch-*.log`；缺少依赖时按根目录 `README.md` 的运行说明手动安装，然后重试。启动器不会安装软件、创建凭据或更改执行策略、防火墙。

已有 `backend/.env` 会照常读取。AI 生成、云端检索等功能仍需要有效的服务凭据及网络；启动成功代表本地前后端可访问。

可选命令（在项目根目录的命令提示符中运行）：

```bat
rem 只检查，不启动或打开浏览器
启动学枢.cmd --check

rem 启动但不自动打开浏览器
启动学枢.cmd --no-browser

rem 端口冲突时手动指定，前端 API 地址会同步指向这个后端
rem 前端 3001 已在默认 CORS 允许范围内；其他前端端口需在 backend/.env 配置 CORS_ORIGINS
启动学枢.cmd --frontend-port 3001 --backend-port 8001
```

正常启动需要已有运行依赖，首次启动不要求先构建前端。前端使用项目的 `npm run dev`，包括其 `predev` 资源准备步骤。
